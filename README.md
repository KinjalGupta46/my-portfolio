## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/portfolio.git
```

Move into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```
